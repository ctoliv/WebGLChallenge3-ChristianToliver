### When using the Perspective Camera, what happens to objects farther away?
- Objects farther away appear smaller, which makes the scene look like it has more depth.

### When using the Orthographic Camera, what happens to object size as distance increases?
- The objects stay about the same size even when they are farther away.

### Which camera looks more like real life? Explain why.
- The Perspective Camera looks more like real life because distant objects appear smaller than objects that are closer.

### Which camera would be best for each?

**A. First-Person Shooter:**  
Perspective, because it gives a realistic sense of depth and distance.

**B. Technical Blueprint Software:**  
Orthographic, because object sizes stay consistent and are easier to compare.

**C. Strategy Game such as Civilization:**  
Orthographic could work well because it gives a clear view of the game area without objects changing size as much because of distance.

### What is the biggest advantage of Orthographic cameras?
- The biggest advantage is that objects keep a consistent size regardless of how far away they are.

### Bonus: Does the difference between Perspective and Orthographic become more obvious when the camera moves?
Yes, the difference becomes more obvious when the camera moves because the Perspective Camera shows more noticeable changes in depth and distance, while the Orthographic Camera keeps object sizes more consistent.
